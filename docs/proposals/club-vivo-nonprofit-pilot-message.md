# Club Vivo Nonprofit Pilot Message

## Email / WhatsApp Draft

Hi [Name],

I am working on Club Vivo, a soccer coaching tool for nonprofit and grassroots programs.

The idea is simple: help coaches create a useful practice plan or quick soccer game from the real constraints they have that day, like player count, space, time, equipment, and age group.

The main feature is Session Builder for full practice planning. There is also a faster lane called Quick Soccer Game for one simple activity when a coach needs something playable quickly.

I am looking for a small, honest pilot with a few coaches. The goal is not a big rollout. It would be to see whether the tool helps coaches save time, feel more prepared, and create sessions they would actually run.

The platform is being designed with protected club data boundaries in mind. Coaches cannot set tenant identity through request inputs, and the system is built around authenticated access and tenant-safe storage.

Would you be open to a short conversation about whether this could fit your coaches or program?
