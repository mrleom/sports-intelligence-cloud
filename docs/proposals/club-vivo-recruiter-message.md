# Club Vivo Recruiter Message

## Short Message

Hi,

I am building Club Vivo, a soccer coaching SaaS product for nonprofit and grassroots sports programs. The product helps coaches turn real-world constraints into usable training sessions and quick soccer games.

The main product wedge is Session Builder. It takes practical inputs like players, space, time, equipment, and objective, then helps produce a coach-ready session. Quick Soccer Game is the faster lane for one playable soccer activity when a coach needs something simple quickly.

The architecture is built on Sports Intelligence Cloud, an AWS serverless SaaS foundation using Cognito, API Gateway, Lambda, DynamoDB, S3, CloudWatch, IAM, and CDK. The platform is designed around tenant-safe access: tenant identity comes from verified auth plus authoritative entitlements, not client input.

For a technical reviewer, the portfolio value is product plus architecture: a real user problem, a clear SaaS product wedge, tenant-safe AWS design, and documentation that separates shipped behavior from future ideas.

I would be glad to walk through the architecture diagram and explain how Club Vivo is structured for a nonprofit pilot.

## One-Line Version

Club Vivo is a soccer coaching SaaS product built on a tenant-safe AWS serverless foundation, with Session Builder as the main planning wedge and Quick Soccer Game as the fast activity lane.
