# Chapter 2 Local Artifact Audit

## 1. Purpose

This audit records generated or local-looking artifacts found in the repository before any ignore, cleanup, delete, move, or rename action.

This slice is documentation only. No files were deleted, moved, renamed, ignored, staged, or committed.

Club Vivo remains the current product and public GitHub face. Sports Intelligence Cloud remains the AWS SaaS platform foundation. This audit does not change app code, backend code, infrastructure, auth, tenancy, IAM, entitlements, DynamoDB keys, routes, Lambdas, or public API contracts.

## 2. Commands Used

The audit used these read-only commands:

- `git status --short --ignored`
- `git ls-files`
- `git ls-files -- <artifact paths>`
- `git check-ignore -v <artifact paths>`
- `Get-ChildItem -Force`
- `Get-ChildItem -Force -Directory`
- PowerShell recursive size checks for selected local artifacts

## 3. Summary Finding

The inspected generated/local-looking artifacts are ignored and not tracked by Git.

`git status --short --ignored` reported the inspected artifacts with `!!` ignore markers. `git ls-files -- <artifact paths>` returned no tracked files for the artifact paths reviewed.

The root tracked files remain normal repository files such as `README.md`, `.gitignore`, `.gitattributes`, `Makefile`, and tracked source/doc folders.

## 5. Other Observations

`git status --short --ignored` produced filename-too-long warnings while scanning nested dependencies inside `infra/cdk/cdk.out.methodology-verify-deploy/` and `infra/cdk/cdk.out.methodology-verify-synth/`.

Those warnings point to bulky generated CDK output with deeply nested staged `node_modules` paths. They do not prove anything is safe to delete, but they are a useful signal that these folders should be reviewed in a later local cleanup slice.

## 7. Recommendations

- Keep tracked repo files as-is.
- Keep current ignore coverage for the audited local artifacts.
- Do not change `.gitignore` in this slice.
- Do not delete local environment files such as `apps/club-vivo/.env.local`.
- Treat `.workspace/` and `infra/cdk/.workspace/` as review-later local context, not automatic cleanup targets.
- Treat CDK output folders as removable locally only after confirming no active synth/deploy review depends on them.
- Treat dependency folders as removable locally only when reinstalling dependencies is acceptable.
